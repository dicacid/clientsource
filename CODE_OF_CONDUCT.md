# Code of Conduct

Prospect Finder B2B aims to be a practical, welcoming open-source project.

Contributors, maintainers and users should communicate respectfully, focus criticism on ideas and code, welcome people new to open source, give actionable feedback and respect privacy.

Harassment, hate speech, intimidation, doxxing, deliberate disruption, threats, sexualized conduct and repeated personal attacks are not acceptable.

Maintainers may edit or remove comments, issues, pull requests or contributions that violate this policy and may restrict participation when necessary.

This applies in the repository, issue tracker, pull requests and other spaces used for project work.
